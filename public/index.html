Your collector is ready.
  1. Drag Collect site styles ↗ to your bookmarks bar.
  2. , then run that bookmark from a public page.
  3. Click Start collection in the site’s collector panel. Results return here.

The collector runs on the source site because browsers block cross-domain style reads. If a site’s security policy blocks it, it cannot be scanned this way. You can always export a completed collection as JSON and import it here.
